## Inputs

Write a program that creates a file called foods.txt and performs the following operations:

- Accept an item from the user and append it to the file.
- Stop accepting items when the user types "done".
- After the user has finished entering items, read the contents of the file and print each item without extra newline characters.

Note: In the Micro:bit online editor, real keyboard input is limited, so this task is mainly for understanding the logic of file handling. If needed, the teacher can adapt it into a list-based activity for simulator use.

## Buttons

Write a program that creates a file called buttons.txt.

1. Everytime a user presses either the 'a' or 'b' button, write "A" or "B" respectively to the buttons.txt file.
2. When the user presses the touch sensor/button stop accepting input.
3. Print the contents of the buttons.txt file.
4. Display on the led screen the total number of times 'a' and 'b' were collectively pressed.
