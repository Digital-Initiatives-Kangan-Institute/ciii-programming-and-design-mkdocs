# AI-Assisted Development

AI tools can help you write code faster, debug issues, and learn new concepts. Understanding how to use them effectively is a valuable modern development skill.

---

## AI as More Than a Chatbot

Modern AI tools go beyond simple question-and-answer. They can:

- Generate code snippets from plain-language descriptions
- Explain what existing code does
- Suggest fixes for bugs
- Help plan and structure projects
- Complete repetitive coding patterns

---

## AI Tools for Web Development

### Copilot

GitHub Copilot works inside VS Code and suggests code as you type. It can generate functions, complete boilerplate, and help with multi-file projects.

- Works inline in your editor
- Understands the context of your project
- Can generate code from comments

### OpenCode

An AI-powered CLI tool that helps with broader software engineering tasks:

- Planning and structuring projects
- Writing and refactoring code across multiple files
- Debugging and explaining issues

---

## Writing Effective Prompts

The quality of AI output depends heavily on your prompts. Good prompts are:

- **Specific** — describe exactly what you need
- **Contextual** — include relevant details about your project
- **Structured** — break complex requests into clear steps

Example:

```
"Create a JavaScript function called calculateTotal 
that accepts an array of prices, adds 10% GST to each 
item, and returns the sum. Use a for loop."
```

Vs a vague prompt:

```
"Write some JavaScript."
```

---

## Keeping Token Use Low

AI tools process your input as **tokens** (roughly, pieces of words). Longer conversations and inputs use more tokens. To work efficiently:

- Be concise in your prompts
- Send only relevant code context
- Break large tasks into smaller, focused requests
- Start new conversations for unrelated topics

---

## Risks to Watch For

- AI can produce incorrect or outdated code — always review and test
- Over-reliance can slow your own learning
- AI may suggest insecure practices (e.g., exposing API keys)
- Generated code might not follow your project's conventions
- Understand what the code does before using it

---

## Using AI for Planning

AI tools can help plan coding tasks before you write anything:

1. Describe what you want to build
2. Ask the AI to break it into steps
3. Review the plan and adjust as needed
4. Tackle one step at a time

---

## Summary

- AI tools help with code generation, planning, and debugging
- Write clear, specific prompts for better results
- Always review and understand AI-generated code
- Keep prompts concise to reduce token usage
- Use AI as an assistant, not a replacement for understanding
