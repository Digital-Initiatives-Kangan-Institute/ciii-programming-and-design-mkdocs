# ICTICT213 – Use Computer Operating Systems and Hardware

## Application

This unit describes the skills and knowledge required to select, install, configure and use computer operating systems and basic computer hardware. This involves configuring the operating system to work with a variety of hardware peripherals and types of ICT equipment.

It applies to individuals working under supervision who provide support to others and apply configuration skills to use and solve issues in operating systems and hardware.

No licensing, legislative or certification requirements apply at the time of publication. [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Elements and Performance Criteria

### 1. Identify operating system and hardware components

* 1.1 Identify and discuss differences between industry standard computer operating systems
* 1.2 Determine ICT organisational requirements and specifications
* 1.3 Identify and select operating system and application software according to required task
* 1.4 Identify internal and external hardware components

### 2. Install and configure operating system, application software and hardware components

* 2.1 Identify relationship between application software, operating system and hardware
* 2.2 Install and configure operating system according to organisational requirements
* 2.3 Identify functions associated with operating system and associated boot process
* 2.4 Use graphical user interface and command line interface and perform basic tasks according to task requirements
* 2.5 Install and configure application software on operating system
* 2.6 Configure operating system to work with required hardware components according to organisational procedures

### 3. Optimise operating system and hardware components and seek feedback

* 3.1 Optimise operating system using tools and vendor utilities
* 3.2 Customise graphical user interface and command line interface using command line techniques
* 3.3 Install identified hardware drivers and check functionality
* 3.4 Seek review and feedback from required personnel and confirm actions were completed

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Foundation Skills

### Reading

* Reviews online and hard-copy ICT information.
* Interprets diagrams, symbols, icons and technical information.

### Writing

* Inputs commands accurately using correct syntax.
* Uses technical terminology appropriately.

### Planning and Organising

* Plans routine technical tasks.
* Makes basic decisions about sequence and timing.

### Technology

* Uses basic digital systems and tools effectively.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Performance Evidence

The learner must demonstrate the ability to:

* Select, install, configure and use a computer operating system.
* Install, configure and run at least one application software package and one hardware component.
* Optimise at least one operating system using tools, drivers and vendor utilities.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Knowledge Evidence

The learner must demonstrate knowledge of:

* Operating system specifications.
* Hardware specifications.
* Application software products.
* Compatibility between operating system versions.
* Operating system optimisation tools.
* Vendor utilities.
* Boot process functions and features.
* Command line techniques.
* Organisational guidelines, procedures and specifications.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Assessment Conditions

Assessment must occur in a workplace or simulated workplace environment with access to:

* Hardware components and drivers.
* Industry-standard operating systems.
* Application software.
* Software configuration guides.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT213/unitdetails)

## Summary (In My Own Words)

This unit teaches students how computer operating systems, software and hardware work together. Students learn to install and configure operating systems, connect and configure hardware devices, install application software, use both graphical and command-line tools, and optimise system performance. By the end of the unit, learners should be capable of preparing a complete computer system, troubleshooting basic issues and configuring it to meet an organisation's requirements.

# ICTICT221 – Identify and Use Specific Industry Standard Technologies

## Application

This unit describes the skills and knowledge required to conduct ongoing review and research of industry-specific technologies in order to identify and apply technologies and techniques that improve organisational activities.

It applies to individuals working under supervision who help maintain business process quality through the use of industry-standard technologies.

No licensing, legislative or certification requirements apply at the time of publication. [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Elements and Performance Criteria

### 1. Prepare to use industry specific technologies

* 1.1 Identify organisational technology upgrades and advancement requirements
* 1.2 Identify technologies required to meet organisational requirements
* 1.3 Classify industry specific technologies according to organisational requirements

### 2. Implement industry specific technologies

* 2.1 Implement and test industry specific technologies according to task requirements
* 2.2 Use features and functions of industry specific technologies according to task requirements
* 2.3 Access and use sources of information according to task requirements

### 3. Evaluate performance of basic industry specific technology

* 3.1 Evaluate performance, usability and benefit to organisation of implemented technologies
* 3.2 Determine and document environmental considerations of implemented technologies
* 3.3 Seek and respond to user according to organisational requirements

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Foundation Skills

### Learning

* Researches and evaluates technical information.
* Expands knowledge of current technologies.

### Oral Communication

* Uses questioning and listening skills to gather information and feedback.

### Reading

* Interprets technical documentation and diagrams.
* Identifies industry technologies and environmental considerations.

### Self-Management

* Organises work according to organisational expectations.
* Prioritises and sequences tasks appropriately.

### Technology

* Uses digital systems and tools effectively.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Performance Evidence

The learner must demonstrate the ability to:

* Identify, implement and evaluate at least three industry-standard technologies.
* Use at least one feature and one function of each technology.
* Comply with organisational and task requirements.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Knowledge Evidence

The learner must demonstrate knowledge of:

* Current ICT technology trends and directions.
* Major industry technology standards.
* Vendor product directions.
* Industry-standard hardware and software products.
* Information gathering and research methodologies.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Assessment Conditions

Assessment must occur in a workplace or simulated workplace environment with access to:

* Industry-standard technologies.
* Required features and functions of those technologies.
* Required hardware and software components.

 [\[training.gov.au\]](https://training.gov.au/training/details/ICTICT221/unitdetails)

## Summary (In My Own Words)

This unit focuses on researching, selecting, implementing and evaluating modern technologies used within the ICT industry. Students learn how organisations determine technology needs, how to test and use different technologies, and how to evaluate whether those technologies provide value. The unit emphasises technology awareness, investigation skills, solution evaluation and staying current with industry trends rather than deep technical configuration. It is essentially a "technology scouting and adoption" unit that teaches students how to identify useful emerging technologies and assess their suitability for business use.
