# React Confetti

## Install and Display Confetti

!!! abstract "Instructions"
    Install the `react-confetti` package and display it when a user completes an action on your page.

    Your task:

    - Install `react-confetti` from npm
    - Create a new page or component that uses the `<Confetti>` component
    - Confetti should appear only after the user clicks a button or completes a goal (e.g. form submitted, quiz answer correct, counter reaches a target)
    - Use `useState` to control whether confetti is shown
    - Add a way to dismiss or restart the confetti

    Push your work to GitHub.

??? tip "Hint - Click to expand"
    Check the [react-confetti documentation](https://www.npmjs.com/package/react-confetti) for all available props and usage examples.

## Make It Meaningful

!!! abstract "Instructions"
    Now integrate confetti into a real feature of your app, not just a toy button.

    Choose one of these scenarios (or invent your own):

    - Confetti fires when a user successfully submits a form
    - Confetti fires when a quiz score is above a threshold
    - Confetti fires after completing a multi-step process
    - Confetti fires when a counter reaches a specific goal

    The confetti should feel like a natural reward for completing something meaningful.

??? tip "Hint - Click to expand"
    Check the [react-confetti documentation](https://www.npmjs.com/package/react-confetti) for all available props. Look for props that control duration, colours, and whether the animation loops.
