# Supabase

We'll be using Supabase to host our databases.  Supabase offers much more functionality such as object storage, OAuth, and serverless functions.  For our purposes, we will be using the database functionality.  Supabase is a starts as free service that allows you to create a PostgreSQL database in the cloud.  You can sign up for a free account at [https://supabase.com](https://supabase.com).

## Database interface

Supabase provides a web interface to manage your database.  You can create tables, add data, and run queries directly from the web interface.  You can also connect to your Supabase database using any PostgreSQL client or library.

We'll be creating our databases from our ERDs and uploading data to them.

It also provide a query editor to run SQL queries against your database.  You can use this to create tables, insert data, and run queries to retrieve data.
