# PostGrest Tasks

For this exercise, you will be using the PostgREST API to interact with databases that you made in the previous ORM tasks.

## Book Database

Use PostgREST to retrieve data from the `books` table you created in the ORM tasks.

- Get all books
- Get books published after 2022

## Vetrinary Clinic Database

- Get all pets
- Get all pets with their owner names
- Get all pets with their owner names, if the pet is a dog

## Music Festival Database

- Get all stages and the performers on each stage with the time that they'll be performing

## IoT Readings Database

- Get all readings where temperature is greater than 21 degrees.  Display Temperature, room name, and time of reading.
- Get all readings where humidity is less than 50%.  Display Humidity, room name, and time of reading.
- Get all readings where temperature is greater than 21 degrees and humidity is greater than 50%.  Display Temperature, Humidity, room name, and time of reading.
