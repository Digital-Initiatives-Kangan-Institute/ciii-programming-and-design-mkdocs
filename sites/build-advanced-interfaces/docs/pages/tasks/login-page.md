# Build and Improve a Login Page

## Create and Upgrade a Login Page

!!! abstract "Instructions"
    Build a login page with HTML, CSS, and JavaScript. Then improve it by adding form validation.

    Your login page must include:

    - Inputs for username/email and password, each with a `<label>`
    - Validation that checks for empty fields and a minimum password length
    - Messages shown on the page when validation fails (not browser alerts)
    - A clean, well-spaced layout

    Write a short before-and-after note describing what you improved.

    Push your work to GitHub.

??? hint "Hint - Click to expand"
    Start by building the form with labels connected to inputs. For validation, prevent the default form submission and check each input's value. Think about where error messages should appear — near the relevant input or in one place. Consider what "empty" means: does whitespace count as input? What is a reasonable minimum password length?
