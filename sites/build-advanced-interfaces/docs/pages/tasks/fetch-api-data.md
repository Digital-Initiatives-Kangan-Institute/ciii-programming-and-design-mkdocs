# Fetch and Display API Data

## Display Data from an API

!!! abstract "Instructions"
    Build a page that fetches data from DummyJSON or MockAPI and displays it on the screen.

    Your page must:

    - Fetch data from one API endpoint
    - Display at least **five records**
    - Show each record in **cards, a list, or a table**
    - Include CSS styling to make the display readable

    Push your work to GitHub.

??? hint "Hint - Click to expand"
    Look at the available endpoints on DummyJSON — there are products, users, posts, quotes, and recipes. Choose one and use `fetch()` to get the data. The response will contain an array of items. Think about which fields (title, price, description, etc.) you want to show and how to create HTML elements to display them.
