# Complete a Task with an AI Agent

## Use an Agent to Build Something

!!! abstract "Instructions"
    Use an AI agent — OpenCode or Copilot in agent mode — to complete a small coding task.

    Choose one of the following or pick your own:

    - Add a new page to your website with a consistent header and footer
    - Add form validation to a login or contact form
    - Create a CSS utility class file and apply it across your pages
    - Refactor inline styles into a linked stylesheet

    Before starting, commit your current work so you can revert if needed.

    Save the prompt you gave the agent and a summary of what it did in a file called `agent-task.md`. Push to GitHub.

??? hint "Hint - Click to expand"
    Describe what you want in plain language, but be specific about the scope: which files to touch, what should change, what should stay the same. Review each change the agent proposes before accepting it. If something is wrong, tell the agent what to fix.

---

## Reflect

!!! abstract "Instructions"
    Add a reflection section to your `agent-task.md` file covering:

    - How was using an agent different from using a chatbot for the same task?
    - What did the agent do well?
    - What did you need to correct or adjust?
    - What is one risk of relying on an agent for coding tasks?

    Push your updated file to GitHub.
