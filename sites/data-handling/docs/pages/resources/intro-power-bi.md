# Module 1: Introduction to Power BI

## Module Overview

Power BI is Microsoft's business intelligence and data visualisation platform. It enables organisations to connect to data from multiple sources, transform and model that data, and create interactive reports and dashboards that support informed decision-making.

In this module, students will gain an understanding of the Power BI ecosystem, explore the differences between reports and dashboards, and learn how Power BI fits into a typical business intelligence workflow.

---

## Learning Outcomes

By the end of this module, students will be able to:

- Describe the purpose of Power BI.
- Identify the key components of the Power BI platform.
- Differentiate between reports and dashboards.
- Explain the stages of a basic business intelligence workflow.
- Navigate the Power BI Desktop interface.

---

## What is Power BI?

Power BI is a business intelligence (BI) tool developed by Microsoft that helps organisations analyse and visualise data. It allows users to connect to various data sources, create relationships between datasets, build visualisations, and share insights with stakeholders.

Businesses use Power BI to:

- Monitor organisational performance.
- Identify trends and patterns.
- Track key performance indicators (KPIs).
- Support data-driven decision making.
- Create interactive reports and dashboards.

### Key Features

- Connects to multiple data sources.
- Provides data transformation capabilities.
- Enables interactive visualisations.
- Supports self-service analytics.
- Offers cloud-based sharing and collaboration.

---

## Why Use Power BI?

Organisations generate large volumes of data every day. Raw data by itself often provides little value until it is transformed into meaningful information.

Power BI helps users:

- Combine data from different systems.
- Analyse business performance.
- Discover insights quickly.
- Present information visually.
- Share reports across teams and departments.

### Example

A retail company may have data stored across:

- Sales systems
- Inventory databases
- Customer relationship management (CRM) systems
- Excel spreadsheets

Power BI can bring this information together into a single report that helps managers understand business performance at a glance.

## Reports vs Dashboards

Although the terms are often used interchangeably, reports and dashboards serve different purposes.

### Reports

Reports are interactive collections of visualisations that typically span multiple pages.

#### Characteristics

- Multiple pages
- Detailed analysis
- Interactive filtering
- Drill-through capabilities
- Rich exploration of data

#### Example

A sales report may include:

- Monthly sales trends
- Product performance
- Regional comparisons
- Customer analysis

---

### Dashboards

Dashboards provide a high-level summary of important information on a single page.

#### Characteristics

- Single-page view
- Executive summary
- Key metrics and KPIs
- Links to detailed reports
- Designed for quick decision-making

#### Example

A sales dashboard may display:

- Total revenue
- Number of customers
- Monthly growth
- Top-performing products

---

### Comparison

| Reports | Dashboards |
|----------|----------|
| Multiple pages | Single page |
| Detailed analysis | Summary information |
| Interactive exploration | Quick monitoring |
| Built primarily in Desktop | Created in the Service |
| Used by analysts | Used by managers and executives |

## The Business Intelligence Workflow

Power BI supports a typical business intelligence process that transforms raw data into actionable insights.

### Step 1: Collect Data

Data may come from:

- Excel files
- CSV files
- Databases
- Web services
- Cloud applications

### Step 2: Transform Data

Data is cleaned and prepared using Power Query.

Common tasks include:

- Renaming columns
- Removing errors
- Correcting data types
- Filtering unwanted records

### Step 3: Model Data

Relationships are created between tables to build a semantic model.

Examples:

- Customers ↔ Orders
- Products ↔ Sales
- Regions ↔ Stores

### Step 4: Visualise Data

Visualisations are created to communicate information effectively.

Examples:

- Bar charts
- Line charts
- Tables
- Treemaps
- KPI cards

### Step 5: Share Insights

Reports and dashboards are published and shared with stakeholders.

Stakeholders may include:

- Team leaders
- Managers
- Executives
- Operational staff

## Power BI Desktop Interface

Understanding the workspace is essential for efficient report development.

### Report View

Used to design report pages and visualisations.

Functions include:

- Creating charts
- Adding slicers
- Formatting visuals
- Building report layouts

### Data View

Used to inspect imported data.

Functions include:

- View tables
- Review columns
- Verify data types

### Model View

Used to create and manage relationships.

Functions include:

- Create relationships
- Configure cardinality
- Organise data models
