# Agent-Assisted Coding Task

## Complete a Task with AI Assistance

!!! abstract "Instructions"
    Use an AI tool (Copilot, OpenCode, or another agent) to help you complete or plan a small coding task.

    While working, save the prompts you use. After completing the task, write a short reflection covering:

    - What the task was
    - How the AI agent helped you
    - One risk or limitation you noticed when using AI for web development

    Push your work and reflection to GitHub.

??? hint "Hint - Click to expand"
    Start by describing your task clearly to the AI tool. Be specific about what you want. Example prompt: "Create a JavaScript function that calculates the total price of selected items from a menu, including 10% GST. Return the total as a number." After the tool responds, review the code, test it, and adjust as needed.
